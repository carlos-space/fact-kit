# AI-platform attribution list for check-commit-body.sh. A message line is AI attribution when it starts
# (after any list marker or emoji) with Co-authored-by:, Assisted-by:, Generated-by:, Made-with:,
# "Generated with" or "Made with", and it names an entry below. Co-authors that match no entry are humans
# and pass.
#
# Format: one entry per line, "<kind> <value>", compared case-insensitively.
#   name   matched as whole words anywhere in the line, so "Claude" also covers "Claude Sonnet 5"; a
#          value may hold several words ("amazon q")
#   email  matched as a substring of the line
# Every entry carries a source comment. "未查證" means no official source was found; the entry stays
# because the platform is in the required list, and should be confirmed or dropped when one turns up.
# Known false positive: a human co-author whose name contains a listed word (for example a person named
# Claude) is blocked too. Credit that person in the message text instead of a Co-authored-by trailer.
